# 사용자 페르소나

## Persona 1: 익명 사용자 (Anonymous User)

### 기본 정보
- **이름**: 최민수
- **나이**: 28세
- **직업**: 프리랜서 디자이너
- **기술 수준**: 중급

### 특성
- 회원 가입 없이 빠르게 URL을 단축하고 싶어함
- 일회성 링크 공유가 주된 목적
- 개인정보 제공을 꺼려함
- 간편함과 속도를 중시

### 목표
- 긴 URL을 빠르게 짧게 만들어 SNS나 메신저에 공유
- 복잡한 절차 없이 즉시 사용
- 링크가 정상 작동하는지 확인

### 니즈
- 회원 가입 없이 URL 단축 기능 사용
- 단축 URL의 즉각적인 생성 및 복사
- 생성한 URL의 유효성 확인

### 주요 시나리오
1. 긴 URL을 입력하고 단축 코드를 받음
2. 단축 URL을 복사하여 SNS에 공유
3. 단축 URL 클릭 시 원본 URL로 리다이렉트됨

### 제약사항
- URL 생성 후 통계 조회 불가
- 생성한 URL 목록 관리 불가
- URL 수정 또는 삭제 불가

## Persona 2: 등록 사용자 (Registered User)

### 기본 정보
- **이름**: 박지영
- **나이**: 32세
- **직업**: 마케팅 매니저
- **기술 수준**: 중상급

### 특성
- 정기적으로 URL 단축 서비스를 사용
- 생성한 링크들을 관리하고 통계를 추적하고 싶어함
- 이메일/비밀번호 기반 회원 가입 선호
- 데이터 기반 의사결정을 중시

### 목표
- 캠페인별로 URL을 생성하고 관리
- 각 링크의 클릭 통계를 확인하여 성과 측정
- 만료일을 설정하여 기간 한정 캠페인 운영

### 니즈
- 이메일/비밀번호로 회원 가입 및 로그인
- 내가 생성한 URL 목록 조회 및 관리
- URL별 상세 클릭 통계 (일별, 국가별, 브라우저별)
- URL 만료일 설정 기능
- 대시보드에서 통계 시각화

### 주요 시나리오
1. 이메일과 비밀번호로 회원 가입
2. 로그인 후 URL 생성 및 만료일 설정
3. 내 URL 목록에서 각 링크의 통계 확인
4. 대시보드에서 전체 클릭 추이 차트 조회
5. 국가별, 브라우저별 분포 차트 확인

### 제약사항
- 이메일 인증 절차 필요 (선택 사항)
- 비밀번호 분실 시 재설정 절차 필요

- **이름**: 김태현
- **나이**: 25세
- **직업**: 대학생 (컴퓨터공학과)
- **기술 수준**: 고급

### 특성
- 소셜 계정을 활용한 간편 로그인 선호
- 별도 비밀번호 관리를 원하지 않음
- Google, GitHub 등의 소셜 계정 보유
- 빠른 접근성과 편의성을 중시

### 목표
- Google이나 GitHub 계정으로 빠르게 로그인
- 등록 사용자와 동일한 기능 활용
- 비밀번호 없이 안전하게 계정 관리

### 니즈
- 소셜 로그인 (Google, GitHub) 기능
- 등록 사용자와 동일한 URL 관리 및 통계 기능
- 소셜 계정 연동 후 즉시 서비스 사용

### 주요 시나리오
1. "Google로 로그인" 버튼 클릭
2. Google 계정 선택 및 권한 승인
3. 자동 로그인 후 URL 생성
4. 내 URL 목록 및 통계 조회
5. 다음 방문 시 자동 로그인 또는 간편 로그인

### 제약사항
- 소셜 계정 서비스 장애 시 로그인 불가
- 소셜 제공자의 정책 변경에 영향받을 수 있음
